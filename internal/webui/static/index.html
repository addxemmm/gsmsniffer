标准 HTTP 接口

同源 API v1 · JSON 响应 · Bearer 认证

身份认证

Authorization: Bearer <TOKEN>
Content-Type: application/json

接口目录

GET /api/v1/status
运行模式、版本、活动任务和在线时长。
GET /api/v1/capabilities
查询当前后端支持的能力。
GET /api/v1/jobs
任务列表。
POST /api/v1/jobs
创建任务，必须提供 shielded_ack: true。
GET /api/v1/jobs/{id}
查询单个任务。
DELETE /api/v1/jobs/{id}
停止任务。
GET /api/v1/observations?kind=frequencies&limit=100&offset=0
分页查询 frequencies、imsi 或 sms。
DELETE /api/v1/observations
显式删除全部观测数据。

响应结构

{ "code": "…", "message": "…", "data": {}, "request_id": "…" }

请通过 HTTPS 或 SSH 隧道访问。不要将 token、真实身份、消息或采集日志提交到公开仓库和镜像。
