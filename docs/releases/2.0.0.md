# 2.0.0 — Shielded laboratory management / 屏蔽实验管理

Released 2026-09-09. Application source revision:
`f5fff089fe00dcaf8c01e33f88f4f7eabc56afd8`.

**Only owned test SIMs and terminals inside an effectively shielded room or enclosure.**
**仅限自有测试 SIM、终端，在有效屏蔽室或屏蔽箱中使用。**

## Delivery / 交付

- Go standard-library backend and embedded responsive Chinese/English console.
- Authenticated `/api/v1`, OpenAPI 3.0, Postman, bounded jobs and audit request IDs.
- Separate default demo and explicitly selected shielded dependency images.
- Clean public Git history; original workspace, logs, captures, PDFs and credentials excluded.
- Breaking change: identities are permanently masked; SMS exposes events only, never message bodies. Legacy root endpoints are retired.

Go 后端、内嵌双语界面、标准接口、完整部署与迁移文档已交付。新版不导出原始身份或短信正文；默认不启动任何任务。
